# `minecraft:cooldown`

- 出现版本：`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Cool down time for a component. After you use an item it becomes unusable for the duration specified by the 'cool down time' setting in this component.
