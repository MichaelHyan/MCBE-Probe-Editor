# `minecraft:behavior.move_to_liquid`

- 出现版本：`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows the mob to move into a liquid when on land.

## `1.21.0`

- 来源：bedrock.dev 官方文档（1.21.0）
- 核实状态：已核实

取值：

```json
{
  "goal_radius": 0.5,
  "material_type": "Any",
  "search_count": 10,
  "search_height": 1,
  "search_range": 0,
  "speed_multiplier": 1.0
}
```
