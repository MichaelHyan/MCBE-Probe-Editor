# `minecraft:behavior.guardian_attack`

- 出现版本：`1.12.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows the guardian to use its laser beam attack. Can only be used by Guardians and Elder Guardians.
