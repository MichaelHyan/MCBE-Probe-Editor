# `minecraft:anger_level`

- 出现版本：`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows this entity to track anger towards a set of nuisances

## `1.21.0`

- 来源：bedrock.dev 官方文档（1.21.0）
- 核实状态：已核实

取值：

```json
{
  "anger_decrement_interval": 1.0,
  "angry_boost": 20,
  "angry_threshold": 80,
  "default_annoyingness": 0,
  "max_anger": 100,
  "remove_targets_below_angry_threshold": true
}
```
