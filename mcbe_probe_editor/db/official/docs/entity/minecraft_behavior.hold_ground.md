# `minecraft:behavior.hold_ground`

- 出现版本：`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

The mob freezes and looks at the mob they are targeting.

## `1.16.0`

- 来源：bedrock.dev 官方文档（1.16.0）
- 核实状态：已核实

取值：

```json
{
  "broadcast": false,
  "broadcast_range": 0.0,
  "min_radius": 10.0
```
