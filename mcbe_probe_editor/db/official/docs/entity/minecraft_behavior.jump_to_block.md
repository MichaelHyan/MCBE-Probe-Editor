# `minecraft:behavior.jump_to_block`

- 出现版本：`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows an entity to jump to another random block.

## `1.21.0`

- 来源：bedrock.dev 官方文档（1.21.0）
- 核实状态：已核实

取值：

```json
{
  "cooldown_range": [
    10,
    20
  ],
  "max_velocity": 1.5,
  "minimum_distance": 2,
  "minimum_path_length": 5,
  "preferred_blocks_chance": 1.0,
  "scale_factor": 0.7,
  "search_height": 10,
  "search_width": 8
}
```
