# `minecraft:renders_when_invisible`

- 出现版本：`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

When set, the entity will render even when invisible. Appropriate rendering behavior can then be specified in the corresponding "minecraft:client_entity".
