# `minecraft:behavior.stalk_and_pounce_on_target`

- 出现版本：`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows a mob to stalk a target, then once within range pounce onto a target, on success the target will be attacked dealing damage defined by the attack component. On failure, the mob will risk getting stuck

## `1.16.0`

- 来源：bedrock.dev 官方文档（1.16.0）
- 核实状态：已核实

取值：

```json
{
  "interest_time": 2.0,
  "leap_distance": 0.8,
  "leap_height": 0.9,
  "max_stalk_dist": 10.0,
  "pounce_max_dist": 5.0,
  "set_persistent": false,
  "stalk_speed": 1.2,
  "strike_dist": 2.0,
  "stuck_time": 2.0
}
```
