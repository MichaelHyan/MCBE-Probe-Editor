# `minecraft:scale_by_age`

- 出现版本：`1.12.0`、`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Defines the entity's size interpolation based on the entity's age.

- 来源：bedrock.dev 官方文档（1.12.0）
