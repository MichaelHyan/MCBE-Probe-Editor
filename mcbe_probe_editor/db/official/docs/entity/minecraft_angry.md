# `minecraft:angry`

- 出现版本：`1.12.0`、`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Defines the entity's 'angry' state using a timer.

## `1.12.0`

- 来源：bedrock.dev 官方文档（1.12.0）
- 核实状态：已核实

取值：

```json
{
  "duration": 25,
  "duration_delta": 0,
  "broadcastAnger": false,
  "broadcastRange": 20
}
```
