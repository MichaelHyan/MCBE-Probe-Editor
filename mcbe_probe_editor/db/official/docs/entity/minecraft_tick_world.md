# `minecraft:tick_world`

- 出现版本：`1.12.0`、`1.16.0`
- 核实状态：**已核实**

## 说明

Defines if the entity ticks the world and the radius around it to tick.

## `1.12.0`

- 来源：bedrock.dev 官方文档（1.12.0）
- 核实状态：已核实

取值：

```json
{
  "radius": 2,
  "distance_to_players": 128,
  "never_despawn": true
}
```

## `1.16.0`

- 来源：bedrock.dev 官方文档（1.16.0）
- 核实状态：已核实

取值：

```json
{
  "distance_to_players": 128,
  "never_despawn": true,
  "radius": 2
}
```
