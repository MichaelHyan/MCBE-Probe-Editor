# `minecraft:ambient_sound_interval`

- 出现版本：`1.12.0`、`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Sets the entity's delay between playing its ambient sound.

## `1.12.0`

- 来源：bedrock.dev 官方文档（1.12.0）
- 核实状态：已核实

取值：

```json
{
  "min": 8.0,
  "max": 16.0,
  "event_name": "ambient"
}
```
