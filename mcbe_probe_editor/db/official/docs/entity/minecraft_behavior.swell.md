# `minecraft:behavior.swell`

- 出现版本：`1.12.0`、`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows the creeper to swell up when a player is nearby. It can only be used by Creepers.

## `1.12.0`

- 来源：bedrock.dev 官方文档（1.12.0）
- 核实状态：已核实

取值：

```json
{
  "start_distance": 10.0,
  "stop_distance": 2.0
}
```
