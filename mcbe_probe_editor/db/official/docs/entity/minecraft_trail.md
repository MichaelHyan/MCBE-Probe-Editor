# `minecraft:trail`

- 出现版本：`1.16.0`、`1.21.0`
- 核实状态：**已核实**

## 说明

Causes an entity to leave a trail of blocks as it moves about the world.

## `1.16.0`

- 来源：bedrock.dev 官方文档（1.16.0）
- 核实状态：已核实

取值：

```json
{
  "block_type": "air",
  "spawn_offset": [
    0,
    0,
    0
  ]
}
```
