# `minecraft:damage_over_time`

- 出现版本：`1.12.0`、`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Applies defined amount of damage to the entity at specified intervals

## `1.12.0`

- 来源：bedrock.dev 官方文档（1.12.0）
- 核实状态：已核实

取值：

```json
{
  "damagePerHurt": 1,
  "timeBetweenHurt": 0
}
```
