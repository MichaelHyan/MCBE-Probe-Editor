# `minecraft:behavior.dragonstrafeplayer`

- 出现版本：`1.12.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows the dragon to fly around looking for a player and shoot fireballs at them. Can only be used by the Ender Dragon.
