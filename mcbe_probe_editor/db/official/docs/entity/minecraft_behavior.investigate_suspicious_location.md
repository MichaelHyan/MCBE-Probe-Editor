# `minecraft:behavior.investigate_suspicious_location`

- 出现版本：`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows this entity to move towards a "suspicious" position based on data gathered in minecraft:suspect_tracking

## `1.21.0`

- 来源：bedrock.dev 官方文档（1.21.0）
- 核实状态：已核实

取值：

```json
{
  "goal_radius": 1.5,
  "speed_multiplier": 1
}
```
