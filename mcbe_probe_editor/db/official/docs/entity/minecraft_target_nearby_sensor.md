# `minecraft:target_nearby_sensor`

- 出现版本：`1.12.0`、`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Defines the entity's range within which it can see or sense other entities to target them.

## `1.12.0`

- 来源：bedrock.dev 官方文档（1.12.0）
- 核实状态：已核实

取值：

```json
{
  "inside_range": 1.0,
  "outside_range": 5.0
}
```
