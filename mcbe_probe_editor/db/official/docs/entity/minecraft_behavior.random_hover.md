# `minecraft:behavior.random_hover`

- 出现版本：`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows the mob to hover around randomly, close to the surface

## `1.16.0`

- 来源：bedrock.dev 官方文档（1.16.0）
- 核实状态：已核实

取值：

```json
{
  "interval": 120,
  "speed_multiplier": 1.0,
  "xz_dist": 10,
  "y_dist": 7,
  "y_offset": 0.0
}
```
