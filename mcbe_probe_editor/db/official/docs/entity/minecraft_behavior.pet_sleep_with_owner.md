# `minecraft:behavior.pet_sleep_with_owner`

- 出现版本：`1.12.0`、`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows the pet mob to move onto a bed with it's owner while sleeping.

## `1.12.0`

- 来源：bedrock.dev 官方文档（1.12.0）
- 核实状态：已核实

取值：

```json
{
  "speed_multiplier": 1.0,
  "search_range": 0,
  "search_height": 1,
  "goal_radius": 0.5
}
```
