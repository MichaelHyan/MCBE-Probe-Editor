# `minecraft:behavior.hide`

- 出现版本：`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows a mob with the hide component to attempt to move to - and hide at - an owned or nearby POI.

## `1.21.0`

- 来源：bedrock.dev 官方文档（1.21.0）
- 核实状态：已核实

取值：

```json
{
  "duration": 1.0,
  "speed_multiplier": 1.0,
  "timeout_cooldown": 8.0
}
```
