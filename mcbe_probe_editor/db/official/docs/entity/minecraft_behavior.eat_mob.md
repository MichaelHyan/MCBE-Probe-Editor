# `minecraft:behavior.eat_mob`

- 出现版本：`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows the entity to eat a specified Mob.

## `1.21.0`

- 来源：bedrock.dev 官方文档（1.21.0）
- 核实状态：已核实

取值：

```json
{
  "eat_animation_time": 1.0,
  "pull_in_force": 1.0,
  "reach_mob_distance": 1.0,
  "run_speed": 1.0
}
```
