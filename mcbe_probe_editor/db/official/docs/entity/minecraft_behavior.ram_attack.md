# `minecraft:behavior.ram_attack`

- 出现版本：`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows this entity to damage a target by using a running attack.

## `1.21.0`

- 来源：bedrock.dev 官方文档（1.21.0）
- 核实状态：已核实

取值：

```json
{
  "baby_knockback_modifier": 0.333333,
  "cooldown_range": [
    10,
    20
  ],
  "knockback_force": 5.0,
  "knockback_height": 0.1,
  "min_ram_distance": 4,
  "ram_distance": 7,
  "ram_speed": 2.0,
  "run_speed": 1.0
}
```
