# `minecraft:behavior.move_to_random_block`

- 出现版本：`1.12.0`、`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows mob to move towards a random block.

## `1.12.0`

- 来源：bedrock.dev 官方文档（1.12.0）
- 核实状态：已核实

取值：

```json
{
  "within_radius": 0.0,
  "block_distance": 16.0
}
```
