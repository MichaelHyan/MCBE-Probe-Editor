# `minecraft:movement.sway`

- 出现版本：`1.12.0`、`1.16.0`、`1.21.0`
- 核实状态：**已核实**

## 说明

This move control causes the mob to sway side to side giving the impression it is swimming.

## `1.12.0`

- 来源：bedrock.dev 官方文档（1.12.0）
- 核实状态：已核实

取值：

```json
{
  "max_turn": 30.0
}
```
