# `minecraft:exhaustion_values`

- 出现版本：`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Defines how much exhaustion each player action should take.

## `1.21.0`

- 来源：bedrock.dev 官方文档（1.21.0）
- 核实状态：已核实

取值：

```json
{
  "attack": 0.1,
  "damage": 0.1,
  "heal": 6,
  "jump": 0.05,
  "lunge": 4,
  "mine": 0.005,
  "sprint": 0.01,
  "sprint_jump": 0.2,
  "swim": 0.01,
  "walk": 0
}
```
