# `minecraft:behavior.find_underwater_treasure`

- 出现版本：`1.12.0`、`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows the mob to move towards the nearest underwater ruin or shipwreck.

## `1.12.0`

- 来源：bedrock.dev 官方文档（1.12.0）
- 核实状态：已核实

取值：

```json

  "search_range": 0,
```
