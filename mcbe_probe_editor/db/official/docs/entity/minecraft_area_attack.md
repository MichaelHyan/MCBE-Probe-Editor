# `minecraft:area_attack`

- 出现版本：`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

A component that does damage to entities that get within range.

## `1.16.0`

- 来源：bedrock.dev 官方文档（1.16.0）
- 核实状态：已核实

取值：

```json
{
  "damage_per_tick": 2,
  "damage_range": 0.2
}
```
