# `minecraft:timer`

- 出现版本：`1.12.0`、`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Adds a timer after which an event will fire.

## `1.12.0`

- 来源：bedrock.dev 官方文档（1.12.0）
- 核实状态：已核实

取值：

```json
{
  "looping": true,
  "randomInterval": true,
  "time": [
    0.0,
    0.0
  ],
  "random_time_choices": []
}
```
