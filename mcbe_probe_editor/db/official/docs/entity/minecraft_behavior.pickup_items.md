# `minecraft:behavior.pickup_items`

- 出现版本：`1.12.0`、`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows the mob to pick up items on the ground.

## `1.12.0`

- 来源：bedrock.dev 官方文档（1.12.0）
- 核实状态：已核实

取值：

```json
{
  "speed_multiplier": 1.0,
  "track_target": false,
  "max_dist": 0.0,
  "goal_radius": 0.5
}
```
