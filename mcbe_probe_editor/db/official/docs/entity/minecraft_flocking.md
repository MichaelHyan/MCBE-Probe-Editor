# `minecraft:flocking`

- 出现版本：`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows entities to flock in groups in water or not.

- 来源：bedrock.dev 官方文档（1.16.0）
- 核实状态：已核实
