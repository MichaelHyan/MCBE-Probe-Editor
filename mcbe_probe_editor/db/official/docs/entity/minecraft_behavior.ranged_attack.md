# `minecraft:behavior.ranged_attack`

- 出现版本：`1.12.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows the mob to use ranged attacks like shooting arrows.

## `1.12.0`

- 来源：bedrock.dev 官方文档（1.12.0）
- 核实状态：已核实

取值：

```json
{
  "speed_multiplier": 1.0,
  "ranged_fov": 90.0,
  "burst_shots": 1,
  "burst_interval": 0.0,
  "attack_interval_min": 0,
  "attack_interval_max": 0,
  "attack_radius": 0.0,
  "charge_charged_trigger": 0.0,
  "charge_shoot_trigger": 0.0
}
```
