# `minecraft:behavior.swim_idle`

- 出现版本：`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows the entity go idle, if swimming. Entity must be in water.

## `1.21.0`

- 来源：bedrock.dev 官方文档（1.21.0）
- 核实状态：已核实

取值：

```json
{
  "idle_time": 5,
  "success_rate": 0.1
}
```
