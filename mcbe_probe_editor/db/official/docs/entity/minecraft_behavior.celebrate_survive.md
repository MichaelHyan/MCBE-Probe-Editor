# `minecraft:behavior.celebrate_survive`

- 出现版本：`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows this entity to celebrate surviving a raid by shooting fireworks.

## `1.21.0`

- 来源：bedrock.dev 官方文档（1.21.0）
- 核实状态：已核实

取值：

```json
{
  "duration": 30.0,
  "fireworks_interval": [
    10,
    20
  ]
}
```
