# `minecraft:behavior.look_at_target`

- 出现版本：`1.12.0`、`1.16.0`、`1.21.0`
- 核实状态：**已核实**

## 说明

Allows the mob to look at the entity they are targetting.

## `1.12.0`

- 来源：bedrock.dev 官方文档（1.12.0）
- 核实状态：已核实

取值：

```json
{
  "look_distance": 8.0,
  "probability": 0.02,
  "look_time": [
    2,
    4
  ],
  "angle_of_view_vertical": 360,
  "angle_of_view_horizontal": 360
}
```
