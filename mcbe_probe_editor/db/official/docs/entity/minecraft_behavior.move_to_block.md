# `minecraft:behavior.move_to_block`

- 出现版本：`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows mob to move towards a block.

## `1.21.0`

- 来源：bedrock.dev 官方文档（1.21.0）
- 核实状态：已核实

```json
  "goal_radius": 0.5,
  "search_height": 1,
  "search_range": 0,
  "speed_multiplier": 1.0,
  "start_chance": 1.0,
  "stay_duration": 0.0,
  "target_offset": [
    0,
    0,
    0
  ],
  "target_selection_method": "nearest",
  "tick_interval": 20
}
```
