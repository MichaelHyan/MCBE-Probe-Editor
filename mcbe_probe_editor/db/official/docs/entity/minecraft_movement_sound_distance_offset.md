# `minecraft:movement_sound_distance_offset`

- 出现版本：`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Sets the offset used to determine the next step distance for playing a movement sound.

## `1.21.0`

- 来源：bedrock.dev 官方文档（1.21.0）
- 核实状态：已核实

取值：

```json
{
  "value": 1.0
}
```
