# `minecraft:looked_at`

- 出现版本：`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Defines the behavior when another entity looks at the owner entity.

## `1.21.0`

- 来源：bedrock.dev 官方文档（1.21.0）
- 核实状态：已核实

取值：

```json
{
  "field_of_view": 26,
  "find_players_only": false,
  "line_of_sight_obstruction_type": "collision",
  "looked_at_cooldown": [
    0,
    0
  ],
  "min_looked_at_duration": 0,
  "scale_fov_by_distance": true,
  "search_radius": 10,
  "set_target": "once_and_stop_scanning"
}
```
