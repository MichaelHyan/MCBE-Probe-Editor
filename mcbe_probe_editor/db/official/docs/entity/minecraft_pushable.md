# `minecraft:pushable`

- 出现版本：`1.12.0`、`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Defines what can push an entity between other entities and pistons.

## `1.12.0`

- 来源：人工确认；取自项目实际值（1.12.0）
- 核实状态：已核实

取值：

```json
{
  "is_pushable": true,
  "is_pushable_by_piston": true
}
```
