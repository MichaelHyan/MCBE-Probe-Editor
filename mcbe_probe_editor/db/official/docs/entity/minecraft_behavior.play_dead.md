# `minecraft:behavior.play_dead`

- 出现版本：`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows this entity to pretend to be dead to avoid being targeted by attackers.

## `1.21.0`

- 来源：bedrock.dev 官方文档（1.21.0）
- 核实状态：已核实

取值：

```json
{
  "apply_regeneration": false,
  "damage_sources": "all",
  "duration": 1.0,
  "force_below_health": 0,
  "random_damage_range": [
    0,
    0
  ],
  "random_start_chance": 1.0
}
```
