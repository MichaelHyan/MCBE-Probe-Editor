# `minecraft:behavior.leap_at_target`

- 出现版本：`1.12.0`、`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows monsters to jump at and attack their target. Can only be used by hostile mobs.

## `1.12.0`

- 来源：bedrock.dev 官方文档（1.12.0）
- 核实状态：已核实

取值：

```json
{
  "yd": 0.0,
  "must_be_on_ground": true
}
```
