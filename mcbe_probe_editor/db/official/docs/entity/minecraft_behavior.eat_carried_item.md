# `minecraft:behavior.eat_carried_item`

- 出现版本：`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

If the mob is carrying a food item, the mob will eat it and the effects will be applied to the mob.
