# `minecraft:behavior.snacking`

- 出现版本：`1.12.0`、`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows the mob to take a load off and snack on food that it found nearby.

## `1.12.0`

- 来源：bedrock.dev 官方文档（1.12.0）
- 核实状态：已核实

取值：

```json
{
  "snacking_cooldown": 7.5,
  "snacking_cooldown_min": 0.5,
  "snacking_stop_chance": 0.0017
}
```
