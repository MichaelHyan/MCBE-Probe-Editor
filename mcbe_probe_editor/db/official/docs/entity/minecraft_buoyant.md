# `minecraft:buoyant`

- 出现版本：`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Enables an entity to float on the specified liquid blocks.

## `1.16.0`

- 来源：bedrock.dev 官方文档（1.16.0）
- 核实状态：已核实

取值：

```json
{
  "apply_gravity": true,
  "base_buoyancy": 1.0,
  "big_wave_probability": 0.03,
  "big_wave_speed": 10.0,
  "drag_down_on_buoyancy_removed": 0.0,
  "simulate_waves": true
}
```
