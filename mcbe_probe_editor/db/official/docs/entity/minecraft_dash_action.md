# `minecraft:dash_action`

- 出现版本：`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Ability for a rideable entity to dash.

## `1.21.0`

- 来源：bedrock.dev 官方文档（1.21.0）
- 核实状态：已核实

取值：

```json
{
  "can_dash_underwater": false,
  "cooldown_time": 1.0,
  "direction": "entity",
  "horizontal_momentum": 1.0,
  "vertical_momentum": 1.0
}
```
