# `minecraft:admire_item`

- 出现版本：`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Causes the mob to ignore attackable targets for a given duration.

## `1.16.0`

- 来源：bedrock.dev 官方文档（1.16.0）
- 核实状态：已核实

取值：

```json
{
  "cooldown_after_being_attacked": 0,
  "duration": 10
}
```
