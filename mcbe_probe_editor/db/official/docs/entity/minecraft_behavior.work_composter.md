# `minecraft:behavior.work_composter`

- 出现版本：`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows the NPC to use the composter POI to convert excess seeds into bone meal.

## `1.21.0`

- 来源：bedrock.dev 官方文档（1.21.0）
- 核实状态：已核实

取值：

```json
{
  "active_time": 0,
  "block_interaction_max": 1,
  "can_empty_composter": true,
  "can_fill_composter": true,
  "can_work_in_rain": false,
  "goal_cooldown": 0,
  "items_per_use_max": 20,
  "min_item_count": 10,
  "speed_multiplier": 0.5,
  "use_block_max": 200,
  "use_block_min": 100,
  "work_in_rain_tolerance": -1
}
```
