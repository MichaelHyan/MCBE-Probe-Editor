# `minecraft:behavior.move_outdoors`

- 出现版本：`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows this entity to move outdoors.

## `1.21.0`

- 来源：bedrock.dev 官方文档（1.21.0）
- 核实状态：已核实

取值：

```json
{
  "goal_radius": 0.5,
  "search_count": 10,
  "search_height": 5,
  "search_range": 15,
  "speed_multiplier": 0.5,
  "timeout_cooldown": 8.0
}
```
