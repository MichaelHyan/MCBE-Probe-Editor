# `minecraft:shareables`

- 出现版本：`1.12.0`、`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Defines a list of items the mob wants to share. Each item must have the following parameters:

## `1.12.0`

- 来源：bedrock.dev 官方文档（1.12.0）
- 核实状态：已核实

取值：

```json
{}
```

- 来源：bedrock.dev 官方文档（1.16.0）
