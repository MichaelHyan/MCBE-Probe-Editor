# `minecraft:on_wake_with_owner`

- 出现版本：`1.12.0`、`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Adds a trigger to call when this pet's owner awakes after sleeping with the pet.
