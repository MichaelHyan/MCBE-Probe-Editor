# `minecraft:behavior.work`

- 出现版本：`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows the NPC to use the POI

## `1.21.0`

- 来源：bedrock.dev 官方文档（1.21.0）
- 核实状态：已核实

取值：

```json
{
  "active_time": 0,
  "can_work_in_rain": false,
  "goal_cooldown": 0,
  "sound_delay_max": 0,
  "sound_delay_min": 0,
  "speed_multiplier": 0.5,
  "work_in_rain_tolerance": -1
}
```
