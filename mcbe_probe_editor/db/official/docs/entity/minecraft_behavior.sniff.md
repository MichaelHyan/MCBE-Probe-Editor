# `minecraft:behavior.sniff`

- 出现版本：`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows this entity to detect the nearest player within "sniffing_radius" and update its "minecraft:suspect_tracking" component state

## `1.21.0`

- 来源：bedrock.dev 官方文档（1.21.0）
- 核实状态：已核实

取值：

```json
{
  "cooldown_range": [
    3,
    10
  ],
  "duration": 1.0,
  "sniffing_radius": 5.0,
  "suspicion_radius_horizontal": 3.0,
  "suspicion_radius_vertical": 3.0
}
```
