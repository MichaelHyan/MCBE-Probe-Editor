# `minecraft:behavior.celebrate`

- 出现版本：`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows this entity to celebrate surviving a raid by making celebration sounds and jumping.

## `1.16.0`

- 来源：bedrock.dev 官方文档（1.16.0）
- 核实状态：已核实

取值：

```json
{
  "duration": 1.0,
  "jump_interval": 0,
  "sound_interval": 0
}
```
