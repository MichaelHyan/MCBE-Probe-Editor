# `minecraft:behavior.mingle`

- 出现版本：`1.12.0`、`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows an entity to go to the village bell and mingle with other entities

## `1.12.0`

- 来源：bedrock.dev 官方文档（1.12.0）
- 核实状态：已核实

取值：

```json
{
  "speed_multiplier": 1.0,
  "cooldown_time": 0.0,
  "duration": 1.0,
  "mingle_partner_type": "empty",
  "mingle_distance": 2.0
}
```
