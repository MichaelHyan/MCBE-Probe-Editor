# `minecraft:preferred_path`

- 出现版本：`1.12.0`、`1.16.0`、`1.21.0`
- 核实状态：**已核实**

## 说明

Specifies costing information for mobs that prefer to walk on preferred paths.

## `1.12.0`

- 来源：bedrock.dev 官方文档（1.12.0）
- 核实状态：已核实

取值：

```json
{
  "max_fall_blocks": 3,
  "jump_cost": 0,
  "default_block_cost": 0
}
```
