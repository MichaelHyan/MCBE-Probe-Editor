# `minecraft:behavior.raid_garden`

- 出现版本：`1.12.0`、`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows the mob to eat crops out of farms until they are full.

## `1.12.0`

- 来源：bedrock.dev 官方文档（1.12.0）
- 核实状态：已核实

取值：

```json
{
  "speed_multiplier": 1.0,
  "search_range": 0,
  "goal_radius": 0.5,
  "max_to_eat": 6,
  "full_delay": 100,
  "eat_delay": 2
}
```
