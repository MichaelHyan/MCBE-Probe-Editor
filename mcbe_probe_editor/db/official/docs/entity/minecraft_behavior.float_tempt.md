# `minecraft:behavior.float_tempt`

- 出现版本：`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows a mob to be tempted by a player holding a specific item. Uses point-to-point movement. Designed for mobs that are floating (e.g. use the "minecraft:navigation.float" component).

## `1.21.0`

- 来源：bedrock.dev 官方文档（1.21.0）
- 核实状态：已核实

取值：

```json
{
  "can_get_scared": false,
  "can_tempt_vertically": false,
  "can_tempt_while_ridden": false,
  "items": [],
  "sound_interval": [
    0.0,
    0.0
  ],
  "speed_multiplier": 1.0,
  "stop_distance": 1.5,
  "within_radius": 0.0
}
```
