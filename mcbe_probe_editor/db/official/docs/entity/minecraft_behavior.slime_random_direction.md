# `minecraft:behavior.slime_random_direction`

- 出现版本：`1.12.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Can only be used by Slimes and Magma Cubes. Allows the mob to move in random directions like a slime.
