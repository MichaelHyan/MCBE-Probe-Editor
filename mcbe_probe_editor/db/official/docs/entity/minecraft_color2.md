# `minecraft:color2`

- 出现版本：`1.12.0`、`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Defines the entity's second texture color. Only works on vanilla entities that have a second predefined color values (tropical fish).
