# `minecraft:behavior.move_indoors`

- 出现版本：`1.12.0`、`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Can only be used by Villagers. Allows them to seek shelter indoors.

## `1.12.0`

- 来源：bedrock.dev 官方文档（1.12.0）
- 核实状态：已核实

取值：

```json

  "timeout_cooldown": 8.0
```
