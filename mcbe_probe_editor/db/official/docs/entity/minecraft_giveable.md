# `minecraft:giveable`

- 出现版本：`1.12.0`、`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Defines sets of items that can be used to trigger events when used on this entity. The item will also be taken and placed in the entity's inventory.
