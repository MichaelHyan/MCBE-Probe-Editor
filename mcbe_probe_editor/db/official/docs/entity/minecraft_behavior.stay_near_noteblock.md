# `minecraft:behavior.stay_near_noteblock`

- 出现版本：`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

The entity will attempt to toss the items from its inventory to a nearby recently played noteblock.

## `1.21.0`

- 来源：bedrock.dev 官方文档（1.21.0）
- 核实状态：已核实

取值：

```json
{
  "listen_time": 30,
  "speed": 1.0,
  "start_distance": 10.0,
  "stop_distance": 2.0
}
```
