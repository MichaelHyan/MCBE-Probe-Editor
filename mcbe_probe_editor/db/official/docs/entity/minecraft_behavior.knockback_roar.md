# `minecraft:behavior.knockback_roar`

- 出现版本：`1.12.0`、`1.16.0`、`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows the mob to perform a damaging knockback that affects all nearby entities.

## `1.12.0`

- 来源：bedrock.dev 官方文档（1.12.0）
- 核实状态：已核实

取值：

```json
{
  "duration": 1.0,
  "attack_time": 0.5,
  "knockback_damage": 6,
  "knockback_strength": 4,
  "knockback_range": 4,
  "cooldown_time": 0.0
}
```
