# `minecraft:behavior.avoid_block`

- 出现版本：`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows this entity to avoid certain blocks.

## `1.21.0`

- 来源：bedrock.dev 官方文档（1.21.0）
- 核实状态：已核实

取值：

```json
{
  "search_height": 0,
  "search_range": 0,
  "sound_interval": [
    3,
    8
  ],
  "sprint_speed_modifier": 1.0,
  "target_selection_method": "nearest",
  "tick_interval": 1,
  "walk_speed_modifier": 1.0
}
```
