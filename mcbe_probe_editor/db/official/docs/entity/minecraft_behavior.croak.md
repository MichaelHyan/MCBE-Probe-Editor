# `minecraft:behavior.croak`

- 出现版本：`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

Allows the entity to croak at a random time interval with configurable conditions.

## `1.21.0`

- 来源：bedrock.dev 官方文档（1.21.0）
- 核实状态：已核实

取值：

```json
{
  "duration": [
    4.5,
    4.5
  ],
  "interval": [
    10,
    20
  ]
}
```
