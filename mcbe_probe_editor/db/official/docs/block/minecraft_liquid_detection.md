# `minecraft:liquid_detection`

- 出现版本：`1.21.0`、`1.26.0`
- 核实状态：**已核实**

## 说明

The definitions for how a block behaves when detecting liquid. Only one rule definition is allowed per liquid type - if multiple are specified, the first will be used and the rest will be ignored.Experimental toggles required: Upcoming Creator Features (in format versions before 1.21.60)
